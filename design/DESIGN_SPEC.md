## 2. 设计原则

1. **科技感**：深色底（近黑蓝）+ 蓝青渐变主题色 + 细网格与辉光背景 + 玻璃拟态面板。
2. **简洁**：每屏一个主任务；信息密度可控（卡片 + 表格 + 折叠说明）；弱信息用三级灰降低干扰。
3. **易操作**：主操作唯一且高亮（渐变按钮）；流程步骤条全局可见、可回退；所有破坏性操作红色并二次确认（Toast 反馈）。

## 4. 布局系统

- **应用框架**：左侧 248px 固定侧边导航（分组：创作 / 资源 / 账户）+ 顶部 64px 玻璃拟态顶栏（搜索、全局状态徽标、主操作按钮）+ 内容区最大宽 1240px。
- **响应式**：`≤1080px` 网格降为 2 列；`≤720px` 侧边栏隐藏（移动端后续可加抽屉导航），网格单列，绑定行降为两行布局。
- **登录页**：左右分栏（1.05 : 1）——左品牌卖点（辉光球装饰），右表单卡片；窄屏隐藏品牌区。

## 5. 页面交互逻辑

### 5.1 全局
- 顶栏搜索全局检索作品/角色/任务；右侧常驻「任务运行中」状态徽标（对应 SSE 任务）。
- 所有请求反馈走右下角 Toast（成功绿 / 失败红），2.5s 自动消失。
- 登录态由路由守卫控制（对应现有 `requiresAuth`）。

### 5.2 登录 / 注册
- 登录/注册同页切换（标题联动）；表单校验失败行内红字 + 输入框红描边。
- **一键体验 Demo**：POC 快速入口，免注册直接进入工作室（对应现有 `quickDemo`）。

### 5.3 工作台（多作品列表）
- 顶部 4 项统计（作品总数 / 合成完成 / 进行中 / 累计音频）。
- 作品卡片：封面渐变 + 状态徽标 + 进度条（映射状态机 `草稿 → 文本已上传 → 解析中 → 待校对 → 校对完成 → 合成中 → 合成完成 → 导出中 → 已完成`）；卡片视图 / 列表视图分段切换；状态与排序下拉筛选。
- **卡片新增「工作空间摘要」行**：制作进度 / 声纹绑定 / 已配音三项量化指标，让人在列表页就能判断哪本书需要动手。
- **点击卡片进入该书的工作空间**（`workspace.html`）；虚线「新建作品」卡片为固定入口。

### 5.3b 作品工作空间（workspace.html，v0.3 核心）

单书的一屏工作台。信息架构：

| 区块 | 锚点 | 承载内容 |
| --- | --- | --- |
| 作品头 | — | 封面 / 标题 / 标签 / 状态机链路 / 整体完成度环形 / 主操作 |
| 制作进度流水线 | `.pipeline` | 上传 → 解析 → 人工校对 → 声纹绑定 → 合成配音 → 导出，6 段各自带状态、耗时、进度与「人工介入」入口 |
| 二级子导航 | `.subnav` | 吸顶锚点，滚动自动高亮当前区块 |
| 解析内容汇总 | `#overview` | 6 项量化指标 + 角色总览卡 + 声纹绑定总览（含克隆合规前置）+ 关系图缩略 |
| 角色与声纹绑定 | `#cast` | 绑定明细（音色 / 语速 / 音高 / 置信复核）、自动匹配推荐、角色合并拆分、绑定预览、情绪→韵律映射 |
| 人物关系图 | `#graph` | SVG 网络图（节点=角色，连线=关系，线宽=强度，虚线=待确认）+ 右侧画像与关系编辑面板 |
| 已解析章节内容 | `#chapters` | 左章节树 / 中片段列表（多维筛选）/ 右片段属性与待复核队列 |
| 已制作配音 | `#audio` | 双色分角色波形成品播放器 + 音频资产表 + 重合成范围与引擎配置 + 实时合成进度 |
| 人工修改留痕 | `#audit` | 版本快照胶囊 + 修改日志（前后对比 diff）+ 逐条回滚 |
| 导出成品 | `#export` | 格式 / 分片 / 字幕 / 片头片尾 / BGM / 响度归一 / 隐式水印 + 导出记录 |

**人工调整（贯穿全流程，可及性优先）**：

- 流水线每一阶段都有「↻ 重跑 / ✎ 再校对 / ↺ 解绑重选 / ▲ 提速 / ⚙ 预设」等人工介入按钮，不用回到向导页。
- 绑定行：角色名、音色、语速、音高、置信归属全部可改；未绑定与低置信用橙/红边框区分，一键补绑。
- 片段行：试听、改文本、改说话人、改情绪强度、改判归属、重合成单段、删除。
  - 视觉编码：左侧橙条 = 人工改过，左侧红条 = 低置信待复核，角标 `<span class="adj-dot">` = 已人工介入。
- 关系图：点节点看画像并改标签/年龄层/音色适配；每条关系可改类型、改强度、删除；可新增关系、恢复自动推导。
- 任何改动都会写入「人工修改留痕」（含前后 diff 与操作人），可按版本快照整体回滚，也可逐条回滚。

### 5.5 新建工作室（旧版四步向导，保留给「从零开始」场景）
1. **上传文本**：作品名 + 大文本域（字数/预计章节/预计时长实时统计）；右侧拖拽上传区 + 解析设置（章节切分 / 情绪识别方式）。「开始解析」提交并锁定为解析中。
2. **解析确认**：左侧解析进度（SSE 驱动，分章→分段→说话人→情绪四阶段文案）+ 结果统计 + 低置信复核卡片（逐条确认说话人）；右侧片段明细表（# / 内容 / 类型 / 说话人 / 情绪·强度），类型徽标区分 叙述/对话/心理；类型筛选 + 片段搜索 + 导出剧本 + 重新解析。
3. **角色绑定**：每行 = 角色（头像+台词数）→ 音色下拉 + 单独试听；旁白固定首行（role_id=0）；「自动绑定」按标签匹配；全局韵律微调（语速/音调/音量）+ 「情绪映射自动覆盖」开关 + 重置全部绑定；右侧绑定预览播放器 + EmotionIR 情绪→韵律映射表（语速/音高）。保存绑定后自动流转到第 4 步（对应 bind→synth 链路）。
4. **合成试听**：范围分段控件（样章先行=前 2 章 / 全本）；开始合成后按钮 loading、进度条 + 阶段文案实时更新（SSE）；完成后出现波形播放器（播放/暂停、进度高亮）+ 下载/分享；右侧任务记录表（可重试）+ 章节进度列表（逐章状态、单章播放与优先级提升）。

### 5.6 音色库
- 分类分段：全部 / 内置 / 我的克隆；音色卡 = 头像 + 名称 + timbre 标注 + 波形 + 标签 + 试听。
- 克隆入口：虚线卡片 + 顶栏主按钮，说明样本要求（1-3 分钟清晰人声）；POC 占位、生产接入上传克隆。

### 5.7 设置
- 三个分区：基本信息（头像/昵称）、创作偏好（默认旁白音色 / 默认合成范围=样章先行 / 情绪识别方式 / 音频格式）、安全（改密 / 退出）。
- 「关于」区展示版本与当前 TTS 引擎状态（POC=Stub 占位，透明化）。

## 7b. v0.3 更新记录（2026-10-02）

### 7b.1 信息架构调整（多作品 → 单书工作空间）
- 新增 `workspace.html`：**每个语音书一个工作空间**，把原本分散在「工作台卡片 / 四步工作室 / 音色库」里的信息重新归位。
- `dashboard.html` 作品卡增加「工作空间摘要」三指标（制作进度 / 声纹绑定 / 已配音），点击进入工作空间；列表视图补「制作进度 / 角色 / 声纹绑定 / 已配音」四列。
- `studio.html` 降级为「从零开始」的新建向导，与工作空间互补而非替代。

### 7b.2 工作空间区块
- **制作进度流水线**：上传 / 解析 / 人工校对 / 声纹绑定 / 合成配音 / 导出 六段，每段带状态、耗时、进度与人工介入入口，点击跳到对应区块。
- **解析内容汇总**：6 项量化指标 + 角色总览 + 声纹绑定总览（含克隆合规前置：实名 / 授权书 / 声纹核验 / 禁公众人物 / 隐式水印）+ 关系图缩略。
- **角色与声纹绑定**：绑定明细可改（角色名 / 音色 / 语速 / 音高 / 置信归属），未绑定与低置信高亮，支持自动匹配推荐、一键补绑、合并 / 拆分 / 降为龙套、删除角色；改动只触发增量重合成。
- **人物关系图**：SVG 网络图随数据渲染（旁白居中 + 五边形分布），点节点联动右侧画像与关系编辑面板；关系可改类型、调强度、删除、新增，可一键恢复自动推导。
- **已解析章节内容**：左章节树 / 中片段列表（类型 + 说话人 + 情绪 + 仅低置信 + 仅人工改 五维筛选 + 空态）/ 右片段属性面板与待复核队列。
- **已制作配音**：双色分角色波形成品播放器（旁白 + 角色双轨）、音频资产表（样章 / 分章 / 分角色轨，可下载与单章重合成）、重合成范围与引擎配置、SSE 实时进度与版本回滚。
- **人工修改留痕**：版本快照胶囊（v1…v5）+ 修改日志（时间 / 类型 / 对象 / 前后 diff / 操作人）+ 逐条回滚。

### 7b.3 人工调整的可及性约定
- 任何 AI 产出的字段都必须能在原地改，并给出「保存中 → 已保存 · 已记入修改日志」的即时反馈。
- 视觉编码统一：橙左边框 = 人工改过，红左边框 = 低置信待复核，`.adj-dot` 角标 = 已人工介入，`.notice` = 待处理聚合条。
- 破坏性操作（删除角色 / 删除关系 / 取消任务 / 归档）一律红色 + 二次确认。

### 7b.4 修复
- **分段控件误隐藏按钮**：原 `bindSegmented` 把同组的分段按钮本身当成面板（按钮上也带 `data-seg-panel`），导致未选中的按钮被 `.hide` 掉（studio.html「样章 / 全本」可见）。现改为跳过 `[data-seg]` 内部元素。
- 赋值表达式残留（关系图渲染里无意义的三元与空语句）已清理。

### 7b.5 新增样式与交互（均带中文注释）
- 样式（`style.css` v0.3 第 13–27 节）：作品头、流水线、二级子导航、区块、指标组、角色卡、置信度条、声纹概览、关系图（图 / 图例 / 详情面板）、章节树、片段卡、配音资产与成品播放器、修改日志与快照、常驻迷你播放器、人工调整工具条、警示条、可编辑态。
- 交互（`app.js` v0.3）：锚点子导航与滚动高亮、流水线跳转、角色卡点选联动关系图详情、关系图节点/边联动、片段五维筛选与空态、行内操作 toast、可编辑字段保存反馈、常驻迷你播放器（全局 `[data-play]` 抢占试听）、`SB.miniPlay` 对外接口。

## 9. v0.2 更新记录（2026-09-30）

### 9.1 修复
- **按钮 hover 覆盖文字**：`.btn:hover`（类+伪类，优先级高于 `.btn-primary`）会把主按钮渐变底覆盖成半透明白、深色文字不可读。已在 `.btn-primary:hover` 显式还原渐变并锁定文字色。
- **页面铺满**：`.content` 移除 1240px 最大宽度限制（PC Web 优先，内容区铺满视口）；设置页改为双栏网格铺满。

### 9.2 音色库深化（`voice-library.html`）
- **自定义上传克隆音色**：三步向导弹窗（选择样本 → 处理中 → 完成）：拖拽/点击上传、60 秒录制入口、样本要求清单、名称与声线类型、初始标签勾选、处理流水（预处理→特征提取→模型注册→质量校验）、完成后质量评分与试听。
- **标签体系**：音色卡标签可移除（×）、可添加（虚线 chip）；顶部标签筛选 chips 多选高亮；**标签管理弹窗**（各标签使用计数、重命名、删除、7 色色板新建标签）。
- **更多 UI/UX**：卡片批量勾选 + 批量操作栏（打标签/导出/删除/取消）；「⋯」更多菜单（重命名/设为默认/替换样本/下载样本/删除）；自定义试听文本；语速/音调滑杆实时数值；克隆处理中卡片（进度条+预计时间）；卡片/列表双视图；排序。

### 9.3 工作室深化（`studio.html`）
- 解析步骤：片段类型筛选（全部/对话/叙述/心理，联动表格）、片段搜索、导出剧本、重新解析、行内逐段试听与编辑入口。
- 绑定步骤：全局韵律微调（整体语速/音调/音量滑杆）、「情绪映射自动覆盖」开关、重置全部绑定。
- 合成步骤：章节进度列表（逐章状态：完成/合成中/排队中，单章播放与优先级提升）。
