# 语音书 · 前端整体设计说明（DESIGN_SPEC）

> 版本 v0.1 · 2026-09-30 · 高保真 HTML/CSS 原型（`design/` 目录）
> 定位：**科技感、简洁、易操作**。本套设计为前端 UI 重构的视觉与交互基准，后续按此在 Vue 前端中落地。

## 2. 设计原则

1. **科技感**：深色底（近黑蓝）+ 蓝青渐变主题色 + 细网格与辉光背景 + 玻璃拟态面板。
2. **简洁**：每屏一个主任务；信息密度可控（卡片 + 表格 + 折叠说明）；弱信息用三级灰降低干扰。
3. **易操作**：主操作唯一且高亮（渐变按钮）；流程步骤条全局可见、可回退；所有破坏性操作红色并二次确认（Toast 反馈）。

## 4. 布局系统

- **应用框架**：左侧 248px 固定侧边导航（分组：创作 / 资源 / 账户）+ 顶部 64px 玻璃拟态顶栏（搜索、全局状态徽标、主操作按钮）+ 内容区最大宽 1240px。
- **响应式**：`≤1080px` 网格降为 2 列；`≤720px` 侧边栏隐藏（移动端后续可加抽屉导航），网格单列，绑定行降为两行布局。
- **登录页**：左右分栏（1.05 : 1）——左品牌卖点（辉光球装饰），右表单卡片；窄屏隐藏品牌区。

## 5. 页面交互逻辑

### 5.1 全局
- 顶栏搜索全局检索作品/角色/任务；右侧常驻「任务运行中」状态徽标（对应 SSE 任务）。
- 所有请求反馈走右下角 Toast（成功绿 / 失败红），2.5s 自动消失。
- 登录态由路由守卫控制（对应现有 `requiresAuth`）。

### 5.2 登录 / 注册
- 登录/注册同页切换（标题联动）；表单校验失败行内红字 + 输入框红描边。
- **一键体验 Demo**：POC 快速入口，免注册直接进入工作室（对应现有 `quickDemo`）。

### 5.3 工作台
- 顶部 4 项统计（作品总数 / 合成完成 / 进行中 / 累计音频）。
- 作品卡片：封面渐变 + 状态徽标 + 进度条（映射状态机 `draft → parsing → pending_review → synthesizing → synth_done`）；卡片视图 / 列表视图分段切换；状态与排序下拉筛选。
- 点击卡片进入工作室；虚线「新建作品」卡片为固定入口。

### 5.4 工作室（核心，四步）
1. **上传文本**：作品名 + 大文本域（字数/预计章节/预计时长实时统计）；右侧拖拽上传区 + 解析设置（章节切分 / 情绪识别方式）。「开始解析」提交并锁定为解析中。
2. **解析确认**：左侧解析进度（SSE 驱动，分章→分段→说话人→情绪四阶段文案）+ 结果统计 + **低置信复核卡片**（逐条确认说话人）；右侧片段明细表（# / 内容 / 类型 / 说话人 / 情绪·强度），类型徽标区分 叙述/对话/心理。
3. **角色绑定**：每行 = 角色（头像+台词数）→ 音色下拉 + 单独试听；旁白固定首行（role_id=0）；「自动绑定」按标签匹配；右侧绑定预览播放器 + EmotionIR 情绪→韵律映射表（语速/音高）。**保存绑定后自动流转到第 4 步**（对应 bind→synth 链路）。
4. **合成试听**：范围分段控件（样章先行=前 2 章 / 全本）；开始合成后按钮 loading、进度条 + 阶段文案实时更新（SSE）；完成后出现**波形播放器**（播放/暂停、进度高亮）+ 下载/分享；右侧任务记录表（可重试）+ 分段试听列表（点击定位）。

### 5.5 音色库
- 分类分段：全部 / 内置 / 我的克隆；音色卡 = 头像 + 名称 + timbre 标注 + 波形 + 标签 + 试听。
- 克隆入口：虚线卡片 + 顶栏主按钮，说明样本要求（1-3 分钟清晰人声）；POC 占位、生产接入上传克隆。

### 5.6 设置
- 三个分区：基本信息（头像/昵称）、创作偏好（默认旁白音色 / 默认合成范围=样章先行 / 情绪识别方式 / 音频格式）、安全（改密 / 退出）。
- 「关于」区展示版本与当前 TTS 引擎状态（POC=Stub 占位，透明化）。

## 6. 组件规范（对应 style.css 类）

| 组件 | 类名 | 关键态 |
| --- | --- | --- |
| 主按钮 | `.btn .btn-primary` | 渐变底 + 悬停上浮 + 发光；loading 转圈禁点 |
| 次按钮 / 危险 | `.btn` / `.btn-danger` | 描边 / 红色软底 |
| 输入 | `.input .select .textarea` | focus 蓝描边 + 3px 光环 |
| 卡片 / 面板 | `.card` / `.panel` | 玻璃拟态，悬停上浮 + 蓝描边 |
| 徽标 | `.badge .ok/.info/.warn/.acc` | 状态机映射，带呼吸圆点 |
| 步骤条 | `.stepper .step` | active 渐变 / done 绿 / 可点击回退 |
| 进度条 | `.progress` | 渐变填充 + 辉光 |
| 播放器 | `.player .wave` | 圆形渐变播放键，波形随播放点亮 |
| 表格 | `.table` | 行悬停浅亮，等宽数字 |
| Toast | `.toast-wrap .toast` | 右下角，成功/错误双色 |

## 7. 与现有 Vue 前端（web/）的接入对照

| 现状 | 本设计 | 改造要点 |
| --- | --- | --- |
| Element Plus 默认样式 | 自有设计系统（style.css） | 引入 token 变量 + 组件类，EP 组件做主题覆盖或逐步替换 |
| Login.vue 单列表单 | 双栏品牌页 | 增加卖点区与 Demo 入口（逻辑不变） |
| Studio.vue 纵向三卡片 | 步骤条 + 分步面板 | 复用现有 API（parse/roles/bindings/synth/SSE），仅重排 UI |
| work store 无 voices | 音色库页 + 绑定预览 | 复用 `GET /voices`、`PUT /works/{id}/bindings` |
| 无工作台/音色库/设置页 | 新增 dashboard / voice-library / settings | 路由新增，后端接口已具备（works 列表、voices） |

## 9. v0.2 更新记录（2026-09-30）

### 9.1 修复
- **按钮 hover 覆盖文字**：`.btn:hover`（类+伪类，优先级高于 `.btn-primary`）会把主按钮渐变底覆盖成半透明白、深色文字不可读。已在 `.btn-primary:hover` 显式还原渐变并锁定文字色。
- **页面铺满**：`.content` 移除 1240px 最大宽度限制（PC Web 优先，内容区铺满视口）；设置页改为双栏网格铺满。

### 9.2 音色库深化（`voice-library.html`）
- **自定义上传克隆音色**：三步向导弹窗（选择样本 → 处理中 → 完成）：拖拽/点击上传、60 秒录制入口、样本要求清单、名称与声线类型、初始标签勾选、处理流水（预处理→特征提取→模型注册→质量校验）、完成后质量评分与试听。
- **标签体系**：音色卡标签可移除（×）、可添加（虚线 chip）；顶部标签筛选 chips 多选高亮；**标签管理弹窗**（各标签使用计数、重命名、删除、7 色色板新建标签）。
- **更多 UI/UX**：卡片批量勾选 + 批量操作栏（打标签/导出/删除/取消）；「⋯」更多菜单（重命名/设为默认/替换样本/下载样本/删除）；自定义试听文本；语速/音调滑杆实时数值；克隆处理中卡片（进度条+预计时间）；卡片/列表双视图；排序。

### 9.3 工作室深化（`studio.html`）
- 解析步骤：片段类型筛选（全部/对话/叙述/心理，联动表格）、片段搜索、导出剧本、重新解析、行内逐段试听与编辑入口。
- 绑定步骤：全局韵律微调（整体语速/音调/音量滑杆）、「情绪映射自动覆盖」开关、重置全部绑定。
- 合成步骤：章节进度列表（逐章状态：完成/合成中/排队中，单章播放与优先级提升）。

### 9.4 新增组件（`assets/style.css` v0.2 区段，均含中文注释）
弹窗（modal-mask/modal/modal-head/body/foot）、标签 chips（chip/x/add/filter + 7 色板）、下拉菜单（menu-wrap/menu/menu-item）、滑杆（slider + param-row）、开关（switch）、拖拽上传区（dropzone）、批量操作栏（batch-bar）、勾选圆点（check-dot）、竖向步骤（vstep）、输入组（input-group）、行内图标钮（icon-btn）、章节进度（chapter-item）。
