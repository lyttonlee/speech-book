## 1. 通用约定

### 1.1 鉴权

- 除 `POST /auth/register`、`POST /auth/login`、`GET /system/public-config` 外，所有接口需 `Authorization: Bearer <JWT>`。
- SSE 端点（`GET /tasks/{id}/stream`）不支持自定义头下的 `EventSource`，token 通过查询参数传入：`?token=<JWT>`。
- 令牌过期用 `POST /auth/refresh` 续期。

### 1.2 请求格式

- `Content-Type: application/json`（POST/PATCH/PUT）。
- 上传文件用 `multipart/form-data`（分片上传）。
- 时间字段统一 ISO 8601（`2026-09-30T11:20:55+08:00`）。

### 1.3 统一响应信封

**成功（HTTP 2xx）**

```json
{ "code": "OK", "data": { }, "request_id": "r-xxxx" }
```

列表接口 `data` 形如：

```json
{ "items": [ ], "total": 120, "page": 1, "page_size": 20 }
```

**错误（HTTP 4xx/5xx）**

```json
{ "code": "WORK_NOT_FOUND", "message": "作品不存在或无权访问", "request_id": "r-xxxx" }
```

### 1.4 分页

列表：`?page=1&page_size=20`（默认 20，最大 100）。响应含 `total/page/page_size`。

### 1.5 幂等

任务类提交（解析/合成/克隆）支持请求头 `Idempotency-Key: <uuid>`；重复提交返回首次创建的同一 `task_id`。

### 1.6 状态码语义

| HTTP | 含义 |
| --- | --- |
| 200/201 | 成功 |
| 400 | 参数错误（code: INVALID_PARAM） |
| 401 | 未认证/令牌失效（code: UNAUTHORIZED） |
| 403 | 无权限（code: FORBIDDEN） |
| 404 | 资源不存在（code: * _NOT_FOUND） |
| 409 | 状态冲突（如重复解析中，code: CONFLICT） |
| 422 | 业务校验失败（如克隆合规未通过，code: CLONE_COMPLIANCE_FAILED） |
| 429 | 限流（code: RATE_LIMITED） |
| 500 | 服务错误（code: INTERNAL） |

## 2. 错误码表

| code | HTTP | 说明 |
| --- | --- | --- |
| OK | 200 | 成功 |
| INVALID_PARAM | 400 | 参数校验失败 |
| UNAUTHORIZED | 401 | 未登录或令牌失效 |
| FORBIDDEN | 403 | 无权限（含非本人作品） |
| WORK_NOT_FOUND | 404 | 作品不存在 |
| ROLE_NOT_FOUND | 404 | 角色不存在 |
| VOICE_NOT_FOUND | 404 | 音色不存在 |

## 3. 认证与账号（/auth）

### 3.1 注册
`POST /auth/register`

```json
{ "email": "u@example.com", "password": "******", "nickname": "创作者A" }
```
响应 `201`：`{ "id": 1, "email": "u@example.com", "nickname": "创作者A" }`

### 3.2 登录
`POST /auth/login`

```json
{ "email": "u@example.com", "password": "******" }
```
响应 `200`：`{ "access_token": "eyJ...", "refresh_token": "eyJ...", "token_type": "bearer", "expires_in": 3600 }`

### 3.3 刷新令牌
`POST /auth/refresh` → `{ "access_token": "..." }`

### 3.4 当前用户
`GET /auth/me` → `{ "id", "email", "nickname", "realname_verified": false, "role": "creator" }`

### 3.5 实名认证（克隆前置）
`POST /auth/realname`

```json
{ "real_name": "张三", "id_card_no": "****", "consent_doc_url": "https://.../consent.pdf" }
```
响应 `200`：`{ "realname_verified": true, "voiceprint_required": true }`

### 3.6 声纹核验
`POST /auth/voiceprint`（`multipart`，上传若干条指定语句音频）
响应 `200`：`{ "voiceprint_checked": true }` —— 通过后解锁克隆提交。

### 3.7 登出
`POST /auth/logout` → `204`

## 4. 作品管理（/works）

### 4.1 作品列表
`GET /works?page=&page_size=&status=&keyword=`

响应 `data.items[]`：`{ "id", "name", "author", "cover_url", "status", "chapter_count", "total_duration", "updated_at" }`

### 4.2 创建作品
`POST /works`

```json
{ "name": "《某某》", "author": "佚名", "intro": "...", "type": "玄幻", "lang": "zh", "cover_url": "" }
```
响应 `201`：`{ "id": 10, "status": "draft" }`

### 4.3 作品详情
`GET /works/{id}` → 含 `status`、统计、`chapter_count` 等完整信息。

### 4.4 更新作品
`PATCH /works/{id}` → 可改 name/author/intro/type/cover。

### 4.5 删除 / 恢复
`DELETE /works/{id}` → 进回收站（30 天）；`POST /works/{id}/restore` → 恢复。

### 4.6 复制作品
`POST /works/{id}/duplicate`（`body`: `{ "reuse_bindings": true, "reuse_params": true }`）→ 新 `work_id`。

### 4.7 作品统计
`GET /works/{id}/stats` → `{ "word_count", "chapter_count", "role_count", "dialogue_ratio", "est_duration", "synthed_duration" }`

### 4.8 分析总览
`GET /works/{id}/analysis` → `{ "word_count", "chapter_count", "role_count", "dialogue_ratio", "emotion_distribution": {"高兴": 120, ...} }`

## 5. 文件上传与结构化（/works/{id}/files）

支持 txt / md / docx / epub，单文件 ≤50MB。大文件前端分片。

### 5.1 上传分片
`POST /works/{id}/files/chunks`（`multipart`: `file`, `chunk_index`, `chunk_total`, `upload_id`）
响应 `200`：`{ "received": 3, "total": 10 }`

### 5.2 合并文件
`POST /works/{id}/files/merge`（`body`: `{ "upload_id", "filename", "file_type" }`）
→ 触发编码识别+清洗+章节/段落切分（异步，返回 `task_id` 或直接置 `文本已上传`）。
响应 `200`：`{ "status": "文本已上传", "chapter_count": 32 }`

### 5.3 原文本 / 结构化对照
`GET /works/{id}/text?chapter_id=` → `{ "chapters": [{ "id", "title", "order", "paragraphs": [{ "id", "order", "text", "type" }] }] }`

### 5.4 章节编辑
`PATCH /works/{id}/chapters/{chapter_id}`（`body`: `{ "title", "order", "action": "merge|split" }`）

### 5.5 增量追加
`POST /works/{id}/files/append`（`multipart` 新章节文本）→ 追加为独立 `Chapter`，不影响已合成。

## 6. 内容解析（/works/{id}/parse）

### 6.1 提交解析
`POST /works/{id}/parse`（`Idempotency-Key` 可选）
响应 `202`：`{ "task_id": "t-100", "status": "pending" }`
> 异步执行：编码清洗 → 章节/段落切分（已在上传完成）→ LLM 旁白/对话/心理分离 + 说话人 + 情绪 + 角色画像（含跨块角色词典）→ 写库 → 置 `待校对`。进度见 §12 SSE。

### 6.2 解析预览（可选）
`GET /works/{id}/parse/preview?chapter_id=` → 单章解析样例（用于快速确认）。

### 6.3 待确认列表
`GET /works/{id}/review-items?type=&low_conf_only=true` → 低置信度 `Segment` 列表（type/speaker/emotion），供校对优先处理。

`POST /works/{id}/roles/{role_id}/merge`（`body`: `{ "source_role_ids": [7,8] }`）→ 合并到当前角色。

### 7.5 台词统计
`GET /works/{id}/roles/{role_id}/stats` → `{ "line_count", "chapter_count", "avg_sentence_len" }`

### 7.6 音色推荐（Top-N）

## 9. 声音克隆（/voices/clone）

仅用户上传自有样本自助；无运营审核。提交前必须 `realname_verified + voiceprint_checked`。

### 9.1 提交克隆
`POST /voices/clone`（`multipart`: `samples`（N 条标准语句音频）, `body`: `{ "name", "consent_doc_url" }`）
- 前置校验：实名 + 授权书 + 声纹（本人）+ 公众人物关键词库。
- 命中公众人物 → `422 BANNED_PERSON`；合规未过 → `422 CLONE_COMPLIANCE_FAILED`。
响应 `202`：`{ "task_id": "t-clone-1", "voice_id": null, "status": "pending" }`

### 9.2 克隆任务状态
`GET /voices/clone/{task_id}` → `{ "status", "progress", "voice_id?(完成后)", "reject_reason?" }`

## 10. 角色-音色绑定（/works/{id}/bindings）

### 10.1 绑定列表
`GET /works/{id}/bindings` → `items[]`: `{ "role_id", "voice_id", "params": { "speed","pitch","volume","style_tag" } }`

### 10.2 自动匹配
`POST /works/{id}/bindings/auto` → 按画像标签批量推荐并应用（返回应用结果，可一键套用）。

### 10.3 设置绑定
`PUT /works/{id}/bindings`（`body`: `{ "items": [ { "role_id": 3, "voice_id": 21, "params": {...} } ] }`）
支持角色级/片段级参数覆盖；旁白（`role_id=0` 或 `type=narrator`）单独配置（FR-425）；心理描写默认跟随角色、可切旁白（FR-426）。

## 11. TTS 合成（/works/{id}/synthesize）

### 11.1 提交合成
`POST /works/{id}/synthesize`（`Idempotency-Key` 可选）

```json
{
  "scope": "sample",            // sample(样章先行) | full(全本) | range(指定章节/范围)
  "range": { "chapter_ids": [1,2] },   // scope=range 时
  "bindings_version": "current",
  "export": { "format": "mp3", "sample_rate": 44100, "with_subtitle": true }
}
```
响应 `202`：`{ "task_id": "t-syn-9", "status": "pending", "reuse_sample": true }`
> 样章（`scope=sample`）仅合成前 1–2 章；满意后 `scope=full` 复用已合成片段（缓存命中跳过）。详见设计文档 5.5。

### 11.2 合成任务状态
`GET /works/{id}/synthesize/{task_id}` → `{ "status", "progress", "audio_url?(完成后)", "subtitle_url?", "failed_segments": 0 }`

### 11.3 失败重试
`POST /tasks/{task_id}/retry` → 仅重试失败片段（片段级，不计入最终失败率）。

## 12. 任务与进度推送（/tasks）

### 12.1 任务详情
`GET /tasks/{id}` → `{ "id", "work_id", "type": "parse|synth|clone", "status", "progress", "payload", "result_ref", "created_at" }`

### 12.2 任务列表
`GET /tasks?work_id=&type=&status=` → 列表（SSE 之外用于首屏/重连补拉）。

### 12.3 SSE 进度流
`GET /tasks/{id}/stream?token=<JWT>`

事件格式（`event: progress` / `event: log` / `event: done` / `event: error`）：

```
event: progress
data: {"progress": 42, "stage": "合成片段 210/500", "speed": "12 seg/s"}

event: log
data: {"level": "info", "msg": "片段 211 完成"}

event: done
data: {"status": "success", "result_ref": "https://.../full.mp3", "subtitle_ref": "https://.../full.srt"}

event: error
data: {"status": "failed", "message": "ENGINE_UNAVAILABLE", "failed_segments": 3}
```

前端 `EventSource` 订阅；断线自动重连，重连后先 `GET /tasks/{id}` 拉最新态再继续。

### 12.4 任务状态机

`pending → running → (progress) → success | failed | partial`
- `failed` 可 `POST /tasks/{id}/retry` → 回到 `running`。
- `partial`：部分片段失败但主流程可继续（如样章成功、个别片段重试中）。

## 13. 校对工作台（/works/{id}/proofread）

### 13.1 三栏数据
`GET /works/{id}/proofread?chapter_id=` →
```json
{
  "chapter": { "id", "title", "order" },
  "paragraphs": [ { "id", "order", "text", "type", "segments": [
      { "id", "text", "speaker_role_id", "speaker_name", "emotion", "intensity", "confidence", "low_conf" }
  ] } ],
  "roles": [ { "id", "name", "level" } ],
  "voices": [ { "id", "name" } ]
}
```

### 13.2 修改片段
`PATCH /works/{id}/segments/{segment_id}`（`body`: `{ "type?", "speaker_role_id?", "emotion?", "intensity?", "style_tag?" }`）
→ 乐观更新 + 写修订记录；AI 原值保留可一键还原。

### 13.3 批量操作
`POST /works/{id}/segments/batch`（`body`: `{ "ids": [...], "patch": {...} }`）

### 13.4 修订历史
`GET /works/{id}/proofread/edits?segment_id=` → 人工修改记录（撤销/重做依据）。

### 13.5 自动保存
前端每次操作即时 `PATCH`；后端幂等写 `Segment` 字段 + `ProofreadEdit` 记录（FR-808）。

## 14. 导出（/works/{id}/export）

### 14.3 下载
导出 `url` 为带签名临时链接（有效期≥7 天可配）。

## 16. 状态机与约束汇总

### 16.1 作品状态机
`草稿 → 文本已上传 → 解析中 → 待校对 → 校对完成 → 合成中 → 合成完成 → 导出中 → 已完成`
- 任意态可 `已归档 / 已删除(回收站)`。
- `待校对 ↔ 校对完成`、`合成完成 → 合成中` 可回退。
- 解析中/合成中不可重复提交（409 CONFLICT）。
- 增量追加仅影响新增 `Chapter`，不回退已 `合成完成` 态（FR-208）。

### 16.2 音色状态
`builtin: 可用`；`clone: pending → training → 可用 | rejected`（rejected 仅因合规/公众人物，无人工审核）。

### 16.3 一致性约束
- 解析禁止每块独立新建角色（角色词典复用）。
- 龙套（`level=extra`）合成走默认旁白/群杂，不强制绑音色。
- 样章与全本使用同一 `bindings` 与参数，保证音色/听感一致。

| GET | /works/{id}/pipeline | 只刷新六段流水线（解析/合成进行时轮询用，比 overview 轻） |
| GET | /works/{id}/assets?kind= | 音频资产列表（kind: sample / chapter / role_track / full） |
| GET | /works/{id}/assets/reindex | 扫描历史合成任务补齐资产（幂等，页面与真实产物不同步时兜底） |

### 18.3 人工校对（/works/{id}）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /works/{id}/proofread?chapter_id= | 三栏校对台数据（章节 / 片段 / 角色 / 音色） |
| PATCH | /works/{id}/segments/{segment_id} | 改片段字段，白名单：type / text / speaker_role_id / speaker_name / emotion / intensity / confidence；改完写 `EditLog` |
| POST | /works/{id}/segments/batch | 批量改，body `{ "ids": [...], "patch": {...} }` |
| POST | /works/{id}/segments/{segment_id}/revert | 还原为 AI 原值（field=all 表示整段还原） |
| GET | /works/{id}/proofread/edits?segment_id= | 该作品的修订历史 |
