## 1. 背景与目标

### 1.1 项目背景

传统有声书制作依赖人工拆书、角色标注、配音录制、后期剪辑，周期长、成本高、产能低。一本 20 万至 50 万字的小说，通常需要多名配音演员、编剧和后期协作，制作周期以周/月计。

随着 LLM、语音合成、声音克隆、图像生成技术成熟，有声书制作可升级为"AI 自动解析 + 人工校对 + 多角色 TTS + 自动成片"的流水线，大幅降低门槛、提高产能。

### 1.2 产品定位

一站式有声书智能制作平台，面向个人创作者、有声书工作室、出版社、内容平台、MCN 机构，提供从小说文本到有声书音频、图文声视频成片的完整生产能力。

### 1.3 产品目标

1. **上传即解析**：自动章节/段落切分、旁白/对话/心理描写分离、说话人识别、情绪分析、角色画像、关系抽取。
2. **角色即音色**：建立音色库，按角色画像自动推荐并绑定音色。
3. **多角色多语音合成**：旁白与不同角色使用不同音色、不同情绪参数。
4. **图文声并茂**（二期）：生成角色立绘/场景图，合成视频有声书。
5. **全流程可编辑**：AI 结果均可人工校对、覆盖。

### 1.4 目标用户

| 用户角色 | 核心诉求 |
| --- | --- |
| 个人创作者 / 网文作者 | 低成本把小说变有声书，快速发布 |
| 有声书工作室 | 批量生产、标准化流程、音色统一 |
| 出版社 / 内容平台 | 版权内容多形态分发 |
| MCN / 自媒体 | 快速产出音频/视频分发 |
| 配音演员 / 声音主播 | 授权音色，获得分成 |
| 运营人员 | 管理内容、审核质量、配置音色和模板 |

### 1.5 典型使用场景

1. 上传 30 万字玄幻小说，系统识别主要角色、推荐音色、生成全书有声书。
2. 上传短篇，选内置音色，快速生成 10 分钟音频。
3. 工作室批量上传多本，统一音色库批量合成。
4. （二期）为主要角色生成立绘与场景图，合成视频有声书。
5. 用户克隆自己声音，授权平台制作有声书并获收益（需合规授权）。

### 1.6 成功指标

| 指标 | 目标值 | 备注 |
| --- | --- | --- |
| 10 万字小说解析完成时间 | ≤ 5 分钟 | 异步任务，非阻塞 |
| 说话人识别准确率（有引导语） | ≥ 95% | 需标注测试集实测 |
| 说话人识别准确率（无引导语） | ≥ 85% | baseline 验证后再承诺 |
| 情绪语气识别准确率 | ≥ 80% | 主观标注，需校准 |
| 角色画像标签可用率 | ≥ 85% | — |
| TTS 合成实时率 RTF | ≤ 0.3 | 本地 GPU |
| 端到端制作 10 万字有声书耗时 | ≤ 2 小时（含人工校对） | — |
| 用户首次制作完成率 | ≥ 60% | — |
| 音频合成失败率 | ≤ 1% | — |
| 成片音画同步误差 | ≤ 100ms | 二期 |

## 2. 项目范围

### 2.1 本期（首期 / V1）范围

首期聚焦**音频有声书最小闭环 + 情绪分析 + 自研声音克隆（合规前置）**：

1. 作品创建与管理。
2. 小说文本上传与结构化（txt / md / docx / epub）。
3. 旁白、对话、心理描写自动识别。
4. 说话人识别与角色归属。
5. **对话语气与情绪分析（保留在首期，直接影响 TTS 听感）**。
6. 角色性格特点与音色适配标签生成。
7. 音色库：内置音色 + 本地开源 TTS 引擎音色。
8. **声音克隆（自研，仅用户上传样本自助克隆）+ 合规前置（实名/授权书/声纹核验/禁公众人物/水印，首期）**。
9. 角色与音色自动匹配、手动绑定。
10. 多角色多语音 TTS 合成（情绪参数映射）。
11. 音频试听、批量合成、失败重试、音频/字幕导出。
12. 人工校对工作台。
13. 基础权限、安全、审核能力（首期不含计费、不含版权承诺/侵权投诉流程）。

### 2.2 后续范围

| 阶段 | 内容 |
| --- | --- |
| M2 智能化 | 人物关系图谱、关系抽取、自定义音色增强、校对增强、多引擎调度、协作权限 |
| M3 多模态 | 图像生成（角色立绘/场景/封面）、时间轴编辑器、视频成片、字幕烧录 |
| M4 商业化 | 计费配额完善、模板复用、开放能力、数据统计 |

### 2.3 非目标（Out of Scope，明确不做）

- 首发**不支持 PDF 解析**（格式复杂，二期评估）。
- **视频生成整体不在首期**（M3 再做）。
- 首发**不做人物关系图谱可视化**（M2）。
- 首发**不做团队协作/审核流**（M4）。
- 首发**不做移动端 H5 编辑**（仅保留试听/查看，且为 P2）。
- 首期**不做计费/配额功能**（M4 评估，数据模型预留扩展）。
- 首期**不做版权承诺签署与侵权投诉流程**（保留生成内容安全审核）。

## 3. 术语定义

| 术语 | 说明 |
| --- | --- |
| 作品 | 一部小说的制作工程，含文本、角色、音色、音频等资源 |
| 章节 | 作品下的结构化单元 |
| 段落 | 章节内文本单元 |
| 片段 | 合成最小单位，通常为一句旁白或一句对话 |
| 旁白 | 非对话的描述性文本 |
| 对话 | 角色说出的文本 |
| 心理描写 | 角色内心活动，归为旁白特殊类型 |
| 角色 | 小说中的人物实体 |
| 角色画像 | 性别、年龄、性格、说话风格、音色适配标签 |
| 音色 | TTS 可调用的声音模型或预设 |
| 音色标签 | 描述音色特征的元数据 |
| 关系图谱 | 角色关系网络（M2） |
| TTS 任务 | 一次批量语音合成作业 |
| 成片 | 音频/图片/字幕合成的最终产物（M3） |
| 龙套角色 | 台词极少的次要角色，采用"默认旁白/群杂"兜底，不逐一绑音色 |

## 4. 产品整体流程

```text
创建作品
  ↓
上传小说文本（txt / md / docx / epub）
  ↓
文本清洗与结构化（编码识别、章节切分、段落切分）
  ↓
AI 内容解析（旁白/对话/心理描写、说话人、情绪、角色画像）
  ↓
人工校对与修正（三栏工作台）
  ↓
音色库匹配与角色音色绑定（含自研克隆音色）
  ↓
多角色多语音 TTS 合成（情绪参数映射）
  ↓
音频试听、重合成、后处理、导出（MP3/WAV/M4A/AAC + 字幕）
  ↓（二期）
图片生成 → 时间轴对齐 → 视频成片
```

## 6. 关键业务流程

### 6.1 从上传到有声书主流程

1. 创建作品 → 2. 上传文本 → 3. 编码识别+清洗 → 4. 章节/段落切分 → 5. 旁白/对话/心理分离 → 6. 说话人识别+角色归并 → 7. 情绪分析 → 8. 角色画像+适配标签 → 9. 用户校对修正 → 10. 音色推荐 → 11. 用户确认/调整绑定（含克隆音色）→ 12. 提交 TTS → 13. 逐片段合成+拼接+后处理 → 14. 试听+重合成 → 15. 导出音频+字幕 →（二期）16. 图像 → 17. 视频成片。

### 6.2 状态流转

```text
草稿 → 文本已上传 → 解析中 → 待校对 → 校对完成
     → 合成中 → 合成完成 → 导出中 → 已完成
```
补充：待校对可回校对完成；合成完成可回合成中；任意状态可归档/删除；任务失败进失败态可重试。

## 15. 技术实现方案（新增）

### 15.1 整体架构

分层：接入层（Web/API）→ 业务服务层（作品/解析/角色/音色/TTS/校对）→ 异步任务层（解析 worker、合成 worker，SSE 进度推送）→ 引擎适配层（LLM 解析、本地 TTS、克隆训练）→ 存储层（对象存储+关系库+向量库+缓存）。

### 15.2 内容解析管线（LLM + 工程兜底）

- **分块策略**：按章节→段落切分；超长章节再按语义窗切片，保留章节/角色上下文头。
- **角色词典**：首轮抽取角色实体与别名，建立全局角色词典，后续分块复用，解决跨章一致性与代称归并。
- **说话人推断**：引导语规则优先（高置信）；无引导语走 LLM 语义 + 角色共现/对话轮次启发式；低置信进待确认列表。
- **情绪分析**：片段级 LLM 打标（标签+强度+语气描述），输出可解释依据。
- **长文本一致性**：跨块信息通过"角色词典 + 向量检索相邻上下文"维持；禁止每块独立新建角色。
- **兜底**：规则层处理引号/破折号等确定性结构；LLM 层处理语义模糊；人工校对最终裁定。

### 15.3 TTS 引擎抽象与情绪映射（重点）

- **引擎抽象层**：定义统一 `SynthesisRequest{text, voiceId, speed, pitch, volume, style, emotion}` 与 `SynthesisResult{audio, duration, timeline}`；本地 IndexTTS / Qwen3-TTS 实现适配器，未来云 API 同构接入。
- **情绪→参数：引擎无关中间表示**：PRD 附录 B 的"气声/颤抖"等细腻参数**未必被本地模型支持**。方案：定义情绪中间层（emotion + intensity + style-tag），再按各引擎能力映射：
  - 支持的：speed/pitch/volume → 直接映射。
  - 不支持的细腻参数（气声/颤抖）→ 降级为"风格标签 style-tag"（若引擎支持）或在合成提示词中表达，否则标注"该引擎不支持，建议换引擎/后期"。
- **能力探测**：启动时探测各引擎支持的参数集，UI 据此开放/禁用对应调节项。
- **RTF ≤0.3**：本地 GPU 批处理 + 片段级并发；失败片段自动重试与降级。

### 15.4 声音克隆（自研，首期）

- 训练：用户上传干声样本（N 条标准语句）→ 自研模型训练专属音色 → 入库为自定义音色。
- 合规前置：用户实名认证 → 授权书上传 → 声纹核验（本人），自助流程无运营审核。禁公众人物关键词库。
- 安全：样本加密、模型加密、生成音频隐式水印、操作日志。
- 风险：训练资源与耗时，需明确单音色训练成本与队列策略（见成本模型）。

### 15.5 异步任务与进度推送

- 长任务（解析、合成、克隆训练）全部异步化，写入任务表，状态机驱动。
- 进度通过 **SSE（Server-Sent Events）** 推送（简单、断线重连友好）；WebSocket 备选。
- 任务状态持久化，服务重启可恢复，支持失败重试与断点续传。

## 17. 数据模型与状态机（新增）

### 17.1 核心实体（字段摘要）

- **Work（作品）**：id, name, author, intro, type, lang, cover, status, ownerId, createdAt。
- **Chapter（章节）**：id, workId, title, order, rawText, structuredFlag。
- **Paragraph（段落）**：id, chapterId, order, text, type(narrative/dialogue/psy)。
- **Segment（片段）**：id, paragraphId, text, speakerRoleId, emotion, intensity, timeline。
- **Role（角色）**：id, workId, name, aliases, level(主/次/龙套), profileJSON。
- **RoleProfile（画像）**：roleId, gender, ageRange, traits[], speakStyle, voiceTags[]。
- **Voice（音色）**：id, name, type(内置/克隆), tags[], engine, modelRef, source, status。
- **VoiceTag（标签）**：id, dim, value, group, scope(系统/用户)。
- **Bind（绑定）**：roleId, voiceId, paramsJSON。
- **Task（任务）**：id, workId, type(解析/合成/克隆), status, progress, payload, resultRef。
- **AudioAsset（音频资产）**：id, segmentId/taskId, url, duration, format。
- **CloneAuth（克隆授权）**：userId, realName, consentDoc, voiceprintCheck, auditStatus。
- **User / Role-Permission**：标准账号与权限表。

### 17.2 作品状态机

`草稿 → 文本已上传 → 解析中 → 待校对 → 校对完成 → 合成中 → 合成完成 → 导出中 → 已完成`，任意态可 `已归档/已删除(回收站)`；`待校对↔校对完成`、`合成完成→合成中` 可回退；任务失败 → `失败` 态可重试。

### 17.3 ER 关系（文字描述）

Work 1—N Chapter；Chapter 1—N Paragraph；Paragraph 1—N Segment；Work 1—N Role；Role 1—1 RoleProfile；Role N—1 Voice(via Bind)；Voice N—N VoiceTag；Work 1—N Task；Task 1—N AudioAsset；User 1—N CloneAuth；User 1—N Work(owner)。

## 18. 质量评估方法（新增）

- **标注测试集**：构建多体裁（玄幻/言情/悬疑/都市）标注样本，覆盖旁白/对话/心理、有/无引导语说话人、情绪标签。
- **指标对齐**：对话分离、说话人（有/无引导语）、情绪准确率、画像完整率，对齐第 1.6 / 13 章验收阈值。
- **baseline 验证**：无引导语说话人 ≥85%、情绪 ≥80% 需先跑 baseline，未达则下调承诺或增加人工兜底。
- **回归**：模型/提示词变更触发回归评测，防止指标回退。
- **人工校验采样**：定期抽样人工评分（角色一致性、听感自然度）。
